Guía — Ejercicio 3 : Configuration d'une app (Valeurs par défaut)

Bonjour ! Cette page reprend toutes les explications sur l'exercice, écrites en français simple, comme si tu étais en classe et que tu découvrais la programmation pour la première fois.

1. De quoi parle l'exercice ?

Imagine une application (comme une appli sur ton téléphone) avec des réglages :

  • le thème : clair ou sombre ;
  • la langue : espagnol, français, anglais…

Ces réglages sont stockés dans un objet en JavaScript. Un objet, c'est comme une petite boîte avec des étiquettes :

const config = {
  tema: "oscuro"
  // El idioma no viene aquí
};

Ici, la boîte contient :

  • tema → "oscuro" (thème sombre)
  • idioma → rien (la langue n'est pas indiquée)

2. C'est quoi une « configuration » ?

Quand tu ouvres une appli sur ton téléphone, tu peux parfois choisir le thème et la langue. Toutes ces préférences, c'est ce qu'on appelle la configuration de l'appli.

Dans l'exercice, cette configuration est représentée par un objet nommé config.

3. C'est quoi un « objet » en programmation ?

Un objet, c'est comme un carnet de réglages avec des étiquettes et des valeurs.

const config = {
  tema: "oscuro"
};

Lis-le comme ça :

Étiquette (nom) Valeur
tema "oscuro"
  • tema = le nom du réglage (le thème)
  • "oscuro" = la valeur choisie (sombre, en espagnol)
  • Les guillemets "..." indiquent que c'est du texte (une chaîne de caractères)

Important : dans cet objet, il n'y a pas de ligne pour idioma (la langue). Donc la langue n'est pas définie.

4. Ce qu'on te demande

L'énoncé dit :

Extrais tema et idioma. Si idioma n'existe pas, utilise la valeur par défaut "es".

En langage humain :

  1. Récupère le thème → on sait que c'est "oscuro".
  2. Récupère la langue → elle n'est pas dans l'objet, donc mets "es" (espagnol) par défaut.

C'est comme si tu demandais à quelqu'un : « Quelle langue as-tu choisie ? » et qu'il ne répond pas. L'appli décide alors : « OK, je mets espagnol par défaut. »

En une phrase :

Tu extrais tema et idioma de l'objet config, et si idioma manque, tu utilises "es" automatiquement.

5. Pourquoi on ne peut pas juste « lire » idioma ?

Si tu faisais ça naïvement :

const idioma = config.idioma;

JavaScript te dirait en gros : « Il n'y a rien ici ». Techniquement, la valeur serait undefined (non définie).

Et si tu affiches :

console.log(tema, idioma);

tu obtiendrais :

oscuro undefined

… ce qui n'est pas ce que l'exercice veut. Il faut oscuro es.

D'où l'idée des valeurs par défaut : quand une info manque, on met une valeur de secours.

6. C'est quoi une « variable » ?

Une variable, c'est une boîte avec un nom où tu ranges une valeur pour t'en servir plus tard.

Exemples :

  • une boîte nommée tema → contient "oscuro"
  • une boîte nommée idioma → doit contenir "es"

À la fin, le code fait :

console.log(tema, idioma);

console.log = afficher à l'écran (dans la console du navigateur ou de l'éditeur). C'est comme un print pour vérifier que tout est bon.

7. La méthode « classique » (sans déstructuration)

Sans la technique demandée, tu pourrais écrire :

const tema = config.tema;
let idioma = config.idioma;

if (idioma === undefined) {
  idioma = "es";
}

Ça marche, mais c'est long. L'exercice te demande d'utiliser la déstructuration, une façon plus courte et moderne en JavaScript.

8. C'est quoi la « déstructuration » ?

Déstructurer = ouvrir l'objet et sortir directement ce dont tu as besoin, en une seule ligne.

Analogie : tu as un sac (config) avec des choses dedans. Au lieu de fouiller une par une, tu dis : « Je sors tema et idioma du sac. »

En JavaScript, au lieu d'écrire :

const tema = config.tema;
const idioma = config.idioma; // undefined, car absent

on peut déstructurer l'objet en une seule ligne et dire : « Si idioma n'existe pas, mets "es" ».

C'est exactement ce que le commentaire te demande :

// ESCRIBE TU DESTRUCTURACIÓN AQUÍ 👇

9. La solution — mot par mot

La ligne à écrire :

const { tema, idioma = "es" } = config;

const

→ « Je crée des variables que je ne changerai pas après. »

{ tema, idioma = "es" }

→ « Dans l'objet, je cherche :

  • une propriété tema → je la mets dans une variable tema
  • une propriété idioma → si elle n'existe pas, je mets "es" »

La partie idioma = "es" est la valeur par défaut.

= config

→ « …et tout ça, je le prends depuis l'objet config. »

10. Que se passe-t-il ligne par ligne ?

Étape 1 — L'objet existe :

config = { tema: "oscuro" }

Étape 2 — Déstructuration :

const { tema, idioma = "es" } = config;
  • JavaScript cherche config.tema → trouve "oscuro" → tema = "oscuro"
  • JavaScript cherche config.idioma → ne trouve rien → applique le défaut → idioma = "es"

Étape 3 — Affichage :

console.log(tema, idioma);

Résultat attendu : oscuro es ✓

  • oscuro → vient de l'objet
  • es → valeur par défaut, car idioma n'était pas dans config

11. Schéma visuel

┌─────────────────────────┐ │ config │ │ ┌─────────────────┐ │ │ │ tema: "oscuro" │───►│──► variable tema = "oscuro" │ └─────────────────┘ │ │ ┌─────────────────┐ │ │ │ idioma: ??? │ │ (absent) │ └─────────────────┘ │ └─────────────────────────┘ │ └──► valeur par défaut ──► variable idioma = "es"

12. Autre exemple pour bien comprendre

Si l'objet était complet :

const config = {
  tema: "claro",
  idioma: "fr"
};

const { tema, idioma = "es" } = config;

console.log(tema, idioma); // claro fr

Ici, idioma existe ("fr"), donc la valeur par défaut "es" n'est pas utilisée.

Règle à retenir : la valeur par défaut ne s'applique que quand la propriété est absente ou vaut undefined.

13. Vocabulaire à retenir

Mot Signification simple
Objet Un groupe de réglages (étiquette → valeur)
Propriété Une étiquette dans l'objet (tema, idioma)
Variable Une boîte nommée pour stocker une valeur
Valeur par défaut Valeur de secours si l'info manque
Déstructuration Extraire plusieurs valeurs d'un objet en une ligne
console.log Afficher des valeurs pour vérifier

14. Résumé en 3 phrases

  1. Tu as un objet config avec le thème, mais sans la langue.
  2. Tu dois créer deux variables : tema et idioma.
  3. Si idioma n'est pas dans l'objet, tu mets "es" grâce à la déstructuration.

Solution complète de l' exercice :

const config = {
  tema: "oscuro"
  // El idioma no viene aquí
};

const { tema, idioma = "es" } = config;

console.log(tema, idioma); // oscuro es
