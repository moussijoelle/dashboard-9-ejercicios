Guía — El podio de una carrera

Ejercicio 13.2 · Arrays y destructuración

Français

Explication du prof (pour débutante)

Bonjour !

Je vais t'expliquer cet exercice comme si on était en classe, sans supposer que tu connais déjà la programmation.

De quoi parle l'exercice ?

Imagine une course à pied. Plusieurs coureurs arrivent à la ligne d'arrivée, dans un ordre précis :

  1. Ana arrive en premier
  2. Luis en deuxième
  3. María en troisième
  4. Pedro en quatrième
  5. Sofía en cinquième

L'exercice te donne cette liste de noms, dans l'ordre d'arrivée, et te demande de récupérer seulement les trois premiers — le podium : or, argent et bronze.

Qu'est-ce qu'un « array » (tableau) ?

En programmation, un array (ou tableau) est comme une liste numérotée.

Pense à une étagère avec des cases :

Position 0 1 2 3 4
Nom Ana Luis María Pedro Sofía
  • La première case (position 0) = 1er = or
  • La deuxième (position 1) = 2e = argent
  • La troisième (position 2) = 3e = bronze

Les cases 3 et 4 (Pedro, Sofía) ne font pas partie du podium pour cet exercice.

Que doit faire ton code ?

Tu pars de :

const corredores = ["Ana", "Luis", "María", "Pedro", "Sofía"];

Tu dois créer trois variables :

  • oro → le 1er (Ana)
  • plata → le 2e (Luis)
  • bronce → le 3e (María)

À la fin, quand le programme affiche :

console.log(oro, plata, bronce);

la console doit montrer : Ana Luis María.

La « destructuration » — en mots simples

Le commentaire te dit d'écrire ta destructuration ici. C'est une façon élégante en JavaScript de dire :

« Dans cette liste, prends le 1er élément pour oro, le 2e pour plata, le 3e pour bronce. »

Au lieu d'écrire trois lignes du genre « oro = le premier », « plata = le deuxième », etc., tu déplies la liste en une seule ligne et tu donnes un nom à chaque morceau.

Analogie : tu ouvres une boîte avec plusieurs objets et tu les poses sur la table en disant « celui-ci c'est l'or, celui-là l'argent, celui-là le bronze ».

Résumé en une phrase : Tu as une liste ordonnée de coureurs ; tu dois extraire les trois premiers noms et les mettre dans trois variables nommées oro, plata et bronce, en utilisant la destructuration.

Español

La forma tradicional de escribirlo

La forma tradicional (sin destructuración) es acceder a cada posición del array con su índice:

const corredores = ["Ana", "Luis", "María", "Pedro", "Sofía"];

const oro = corredores[0];
const plata = corredores[1];
const bronce = corredores[2];

console.log(oro, plata, bronce); // Ana Luis María

Qué hace cada línea

  • corredores[0] → primer elemento → Ana (oro)
  • corredores[1] → segundo → Luis (plata)
  • corredores[2] → tercero → María (bronce)

Recuerda: en JavaScript los arrays empiezan en 0, no en 1.

Comparación con destructuración

Tradicional (3 líneas):

const oro = corredores[0];
const plata = corredores[1];
const bronce = corredores[2];

Con destructuración (1 línea, lo que pide el ejercicio):

const [oro, plata, bronce] = corredores;

Hacen lo mismo: la destructuración es solo una forma más corta de escribir lo mismo.

En resumen: ambas formas extraen Ana, Luis y María del array. La tradicional usa índices ([0], [1], [2]); la destructuración lo hace en una sola línea con corchetes a la izquierda del =.
