Guía del ejercicio 1

Destructuración de objetos — El perfil de usuario

Français

Bonjour ! Voyons cet exercice ensemble

Tu as déjà bien compris la théorie. Là, c'est la pratique : un petit exercice très concret.

C'est quoi l'histoire de cet exercice ?

On te donne la fiche d'un utilisateur nommé Carlos. C'est l'objet usuario :

const usuario = {
  nombre: "Carlos",
  edad: 28,
  pais: "España",
  profesion: "Desarrollador"
};

C'est comme une carte d'identité numérique avec 4 infos :

Étiquette (propriété) Valeur
nombre"Carlos"
edad28
pais"España"
profesion"Desarrollador"

Tout est dans la boîte usuario.

Ce qu'on te demande de faire

L'énoncé dit :

Extrae las propiedades nombre, edad y pais en variables independientes usando una sola línea de código.

En français :

Sors de l'objet usuario les infos nom, âge et pays, et mets-les dans 3 variables séparées, en une seule ligne.

Tu ne touches pas à profesion pour cet exercice — on ne te demande que 3 choses sur 4.

Le code de base de l'exercice

const usuario = {
  nombre: "Carlos",
  edad: 28,
  pais: "España",
  profesion: "Desarrollador"
};

// ESCRIBE TU DESTRUCTURACIÓN AQUÍ 👇


console.log(nombre, edad, pais); // Debe mostrar por consola: Carlos 28 España

Pourquoi il y a une ligne vide avec un commentaire ?

// ESCRIBE TU DESTRUCTURACIÓN AQUÍ 👇

C'est ton espace pour écrire ta solution. C'est là que tu mets la ligne de destructuration.

Et cette ligne en bas ?

console.log(nombre, edad, pais);

Ça veut dire : « Affiche à l'écran les variables nombre, edad et pais. »

Le résultat attendu :

Carlos 28 España

Problème pour l'instant : ces variables nombre, edad et pais n'existent pas encore. Elles ne sont pas créées tant que tu n'as pas écrit ta destructuration.

C'est comme si on te disait « écris le prénom sur le papier » alors que tu n'as pas encore sorti le prénom de la fiche.

Ce que tu dois faire (en mots simples)

  1. Regarder l'objet usuario — les données sont déjà là.
  2. Écrire une ligne qui sort nombre, edad et pais de cet objet.
  3. Créer 3 variables avec exactement ces noms : nombre, edad, pais.
  4. Le console.log pourra alors les utiliser et afficher Carlos 28 España.

Analogie du prof

Imagine une boîte à chaussures étiquetée usuario. Dedans :

  • un papier « nom : Carlos »
  • un papier « âge : 28 »
  • un papier « pays : España »
  • un papier « métier : Desarrollador » (on ne le sort pas pour cet exercice)

On te dit : « Sors le nom, l'âge et le pays, mets chaque info dans une petite enveloppe, et fais-le en une seule phrase. »

La destructuration, c'est cette phrase magique qui ouvre la boîte et remplit les 3 enveloppes d'un coup.

Ce qu'il ne faut pas faire ici

  • Ne pas réécrire l'objet usuario — il est déjà là.
  • Ne pas faire 3 lignes séparées (const nombre = usuario.nombre etc.) — l'énoncé demande une seule ligne.
  • Ne pas oublier pais — le console.log en a besoin.
  • Ne pas extraire profesion — ce n'est pas demandé (mais ce n'est pas grave si tu la mets en plus ; l'important c'est d'avoir les 3 autres).

Indice (sans la réponse complète)

Tu as appris que la forme générale ressemble à :

const { ... } = usuario;
Entre les { }, tu mets les noms des propriétés que tu veux sortir de la boîte : nombre, edad et pais.

Résumé

En une phrase :
Tu dois utiliser la destructuration pour créer les variables nombre, edad et pais à partir de l'objet usuario, en une ligne, pour que le console.log affiche : Carlos 28 España.
