Ejercicio 13.1 · El perfil de usuario (Objetos)

Français

Introduction — Qu'est-ce que la destructuration ?

La destructuration est une fonctionnalité de JavaScript (ES6) qui permet d'extraire des données d'un objet ou d'un tableau et de les mettre directement dans des variables, en une seule ligne.

D'abord : c'est quoi un objet ?

Imagine une fiche d'identité (un profil utilisateur) :

const usuario = {
  nombre: "Ana",
  edad: 28,
  pais: "España",
  profesion: "Desarrolladora"
};

Pour lire une info, on écrit par exemple usuario.nombre → ça donne "Ana".

La destructuration, c'est quoi ?

Destructurer = déballer la boîte et mettre chaque chose directement dans un petit pot à part, en une seule ligne.

Sans destructuration (la méthode longue) :

let nombre = usuario.nombre;
let edad = usuario.edad;

Avec destructuration (la méthode courte) :

const { nombre, edad } = usuario;
Analogie : au lieu de chercher dans le placard à chaque fois (usuario.nombre, usuario.edad…), tu sors tout ce dont tu as besoin une fois et tu l'as sous la main.

1. Destructuration des tableaux (arrays)

Un tableau = une liste ordonnée : 1er élément, 2e élément, 3e…

Sans destructuration :

let resultado = cookie.split('=');
let llave = resultado[0];   // "usuario"
let valor = resultado[1];     // "Carlos"

Avec destructuration :

const [llave, valor] = cookie.split('=');

Les crochets [] = « le 1er va dans llave, le 2e dans valor ».

  • Ignorer un élément : const [, valor] = cookie.split('=');
  • Valeur par défaut : const [llave, valor = "sin-valor"] = cookie.split('=');

2. Destructuration des objets

On utilise des accolades {}, pas des crochets.

const { nombre, edad } = usuario;

Renommer une variable :

const { profesion: trabajo } = usuario;
console.log(trabajo);    // "Desarrolladora"
console.log(profesion);  // ❌ Error: profesion n'existe pas comme variable

3. Destructuration dans les paramètres d'une fonction

function saludar({ nombre, edad }) {
  console.log(`Hola, me llamo ${nombre} y tengo ${edad} años.`);
}

const persona = { nombre: "Lucas", edad: 22, ciudad: "Madrid" };
saludar(persona);

C'est très utilisé en React pour les props.

4. Destructuration imbriquée

const auto = {
  marca: "Toyota",
  motor: {
    cilindrada: "2.0L",
    caballos: 150
  }
};

const { motor: { caballos } } = auto;
console.log(caballos);  // 150

5. L'opérateur rest (...)

const configuracion = {
  id: "98A",
  tema: "oscuro",
  idioma: "es",
  notificaciones: true
};

const { id, ...ajustesVisuales } = configuracion;
// id → "98A"
// ajustesVisuales → { tema: "oscuro", idioma: "es", notificaciones: true }

En quoi consiste l'exercice ?

  1. Créer un objet qui représente une personne.
  2. Utiliser la destructuration pour en extraire des infos.
  3. Passer cet objet à une fonction qui déstructure ses paramètres.
  4. Peut-être renommer une propriété, ou utiliser ...rest.
Résumé : La destructuration, c'est une façon élégante de sortir des données d'un objet ou d'un tableau et de les mettre dans des variables directement, sans répéter .nombre, .edad, [0], [1] à chaque fois.

Español

Explicación línea por línea

const { nombre, edad } = usuario;

Imagina que usuario es una caja con etiquetas. Esta línea abre la caja y saca dos cosas con nombres concretos.

ElementoSignificado
constDeclara una constante: una variable que no se puede reasignar después.
{ nombre, edad }Sintaxis de destructuración. Busca las propiedades nombre y edad y crea variables con esos nombres.
=Operador de asignación: toma los datos de la derecha y los asigna a la izquierda.
usuarioEl objeto de origen del que sacas los datos.

¿Qué pasa al ejecutar la línea?

PasoQué ocurre
1JavaScript mira usuario
2Busca la propiedad nombre → "Ana"
3Crea const nombre = "Ana"
4Busca la propiedad edad → 28
5Crea const edad = 28

Esquema visual

const   {   nombre ,   edad   }   =   usuario ;
  │       │     │        │      │       │
  │       │     │        │      │       └── Objeto del que sacas datos
  │       │     │        │      └── Asignación
  │       │     │        └── Segunda propiedad → variable edad
  │       │     └── Primera propiedad → variable nombre
  │       └── Sintaxis de destructuración (no es un objeto nuevo)
  └── Declara constantes

Detalle importante: Si una propiedad no existe en el objeto, la variable vale undefined (no da error por sí solo).

¿nombre y edad son datos del usuario?

Sí. Viven dentro del objeto usuario como propiedades:

const usuario = {
  nombre: "Ana",
  edad: 28,
  pais: "España",
  profesion: "Desarrolladora"
};

La destructuración no inventa esos datos: los saca del objeto y los pone en variables sueltas para usarlos más fácil.

La destructuración sirve para extraer varios valores de un objeto (o array) y declarar varias variables a la vez.
const { nombre, edad } = usuario;

Es lo mismo que:

const nombre = usuario.nombre;
const edad = usuario.edad;

Ejemplo con profesion y trabajo

A veces la propiedad del objeto tiene un nombre, pero tú quieres otro nombre para la variable. Ahí usas :.

const { profesion: trabajo } = usuario;

console.log(trabajo);            // "Desarrolladora" ✅
console.log(profesion);          // ❌ Error: profesion no existe como variable
console.log(usuario.profesion);  // "Desarrolladora" ✅ (sigue en el objeto)
ElementoSignificado
profesionNombre de la propiedad dentro de usuario
:"Voy a llamar a esto de otra forma"
trabajoNombre de la variable que se crea

Equivale a:

const trabajo = usuario.profesion;

Comparación rápida

// Mismo nombre en objeto y variable
const { nombre } = usuario;
// nombre = usuario.nombre

// Nombre distinto en la variable
const { profesion: trabajo } = usuario;
// trabajo = usuario.profesion

Forma tradicional vs destructuración — ¿Es lo mismo?

Sí. Las dos formas hacen exactamente lo mismo:

Forma tradicional (larga)

const nombre = usuario.nombre;
const edad = usuario.edad;

Aquí sacas nombre y edad de usuario y los guardas en variables.

Forma con destructuración (corta)

const { nombre, edad } = usuario;

Aquí también sacas nombre y edad de usuario. Solo que JavaScript lo hace en una línea.

TradicionalDestructuración
¿De dónde sale el dato?De usuarioDe usuario
¿Qué obtienes?Variables nombre, edadVariables nombre, edad
¿El objeto cambia?NoNo
DiferenciaMás líneas, más repetición (usuario.)Menos líneas

Ejemplo paso a paso (como en un ejercicio)

const usuario = {
  nombre: "Ana",
  edad: 28,
  profesion: "Desarrolladora"
};

// PASO 1 — Forma tradicional (para entender)
const nombreTradicional = usuario.nombre;
const edadTradicional = usuario.edad;

console.log(nombreTradicional);  // Ana
console.log(edadTradicional);    // 28

// PASO 2 — Forma con destructuración (el atajo)
const { nombre, edad } = usuario;

console.log(nombre);  // Ana (mismo resultado)
console.log(edad);    // 28 (mismo resultado)

Analogía simple

usuario es una mochila con bolsillos: nombre, edad, profesion.

  • Tradicional: abres el bolsillo nombre y pones lo que hay en una cajita. Repites con edad.
  • Destructuración: dices "sácame nombre y edad de la mochila" — todo en una frase.

La mochila (usuario) sigue intacta. Solo copiaste valores a variables.

Lo que quizá te liaba: Pensabas "primero saco los datos… y después declaro variables con destructuración".

En realidad: Declarar variables ES sacar los datos. Destructuración es otra sintaxis para hacerlo.

No hace falta hacer las dos cosas en un programa real: eliges una. En el curso a veces piden ambas solo para comparar.

Cuándo usar cada una

  • Tradicional (usuario.nombre): cuando solo necesitas una propiedad.
  • Destructuración: cuando necesitas varias propiedades y vas a usarlas muchas veces.

¿Cómo sacar todos los datos del objeto?

Si quieres sacar todas las propiedades, las pones todas entre las llaves, separadas por comas:

const usuario = {
  nombre: "Ana",
  edad: 28,
  pais: "España",
  profesion: "Desarrolladora"
};

const { nombre, edad, pais, profesion } = usuario;

console.log(nombre);     // "Ana"
console.log(edad);       // 28
console.log(pais);       // "España"
console.log(profesion);  // "Desarrolladora"

Cosas importantes

  1. Tienes que poner el nombre de cada propiedad. Si te olvidas pais, no se crea la variable pais.
  2. El orden no importa en objetos: const { nombre, edad, profesion } = usuario; es igual que const { profesion, nombre, edad } = usuario;
  3. No estás obligada a sacar todo. Solo sacas lo que necesites: const { nombre, edad } = usuario; está bien.
  4. El objeto usuario no desaparece. Sigues teniendo usuario completo.

Comparación rápida

// Tradicional — 4 líneas
const nombre = usuario.nombre;
const edad = usuario.edad;
const pais = usuario.pais;
const profesion = usuario.profesion;

// Destructuración — 1 línea
const { nombre, edad, pais, profesion } = usuario;

Mismo resultado, menos repetición.

Conclusión

La destructuración sirve sobre todo para:

  • Escribir menos código
  • Ponerlo en una línea (o en menos líneas)
  • No repetir usuario. una y otra vez

Tu conclusión en una frase:
La destructuración es un atajo para sacar varios datos de un objeto (o array) y declarar varias variables de golpe, sin repetir tanto.
