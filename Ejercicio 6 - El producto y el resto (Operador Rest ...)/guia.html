Explication du exercice (en français, niveau débutant)

Bonjour ! Pas de souci, on va y aller doucement. 😊

De quoi parle l'exercice ?

Imagine une fiche produit dans une boutique en ligne, comme sur Amazon :

  • un numéro (l'identifiant du produit)
  • un prix
  • un nom
  • une marque
  • la quantité en stock

En programmation, on regroupe souvent ces infos dans une boîte qu'on appelle un objet. Ici, cette boîte s'appelle producto (produit).

const producto = {
  id: "PROD-10",
  precio: 29.99,
  nombre: "Teclado Mecánico",
  marca: "Logitech",
  stock: 15
};

Chaque ligne à l'intérieur des { } est une propriété : un nom + une valeur.

Ce qu'on te demande de faire

Tu dois faire deux choses avec cette fiche :

1. Sortir id et precio à part

Tu dois les mettre dans deux variables séparées, comme si tu prenais deux infos importantes et tu les posais sur le bureau :

  • une variable id → "PROD-10"
  • une variable precio → 29.99

2. Mettre tout le reste dans un nouvel objet detalles

Les autres infos (nombre, marca, stock) ne doivent pas disparaître. On les regroupe dans un nouvel objet appelé detalles (détails).

Résultat attendu :

detalles = {
  nombre: "Teclado Mecánico",
  marca: "Logitech",
  stock: 15
}

L'astuce : la déstructuration + l'opérateur « rest » (...)

En JavaScript, au lieu d'écrire beaucoup de lignes à la main, on peut ouvrir la boîte et répartir le contenu en une seule ligne :

const { id, precio, ...detalles } = producto;

Lis cette ligne comme ceci :

  • { } → « je vais prendre des choses dans l'objet »
  • id, precio → « je veux ces deux-là, chacun dans sa propre variable »
  • ...detalles → « tout le reste, mets-le dans un objet appelé detalles »

Le ... s'appelle l'opérateur rest (reste). Ce n'est pas le même sens que le modulo % ; ici, « rest » veut dire « ce qui reste ».

Pourquoi on fait ça ?

C'est utile quand certaines infos sont plus importantes que d'autres.

Exemple concret :

  • id et precio → souvent affichés en gros (référence + prix)
  • nombre, marca, stock → détails secondaires (description, marque, disponibilité)

Tu sépares ce qui est prioritaire du reste, sans recopier tout à la main.

Ce que tu dois voir à l'écran

Quand tu lances le programme :

console.log(id, precio);
// → PROD-10 29.99

console.log(detalles);
// → { nombre: 'Teclado Mecánico', marca: 'Logitech', stock: 15 }

Si tu obtiens ça, c'est bon. ✅
